# Project instructions

Use English for all project content, including code, comments, documentation, configuration descriptions, and user-facing messages. Do not use Russian in project files.

Commit every completed change you make automatically, using English Conventional Commit messages (for example, `feat: ...`, `fix: ...`, or `docs: ...`). Commit only your own changes; do not include unrelated user changes. Keep AI authorship disclosure in the README, not in commit messages.
